# XE-Darc Launcher

XE-Darc launcher is the entrypoint for the XE-Darc system.

## Requirements

### Hardware

- Apple device with MacOS Tahoe.

### Experience

- Familiarity with web code/IDE/agentic environments.

## Setup 

1. Download the [current release](https://github.com/Agent54/xe-darc-launcher/releases/latest).
2. Open the `Darc.dmg` file.
3. Drag the `Darc` icon to Applications folder.
4. Launch. You will then find the app in your menu bar.

> [!NOTE]
> If the package cannot open, launch Terminal and type `xattr -d com.apple.quarantine Darc.dmg` to bypass Gatekeeper.
